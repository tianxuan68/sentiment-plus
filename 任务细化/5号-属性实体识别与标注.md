# 三、实现步骤

1. 定义 **≥5 类** 属性实体（示例口径，组内可改名但须固定）：质量、价格、物流、服务、包装（或同级五类）。
2. **双标注**：
   - 序列：BIO → `data/processed/aspect_ner.jsonl`  
     每行示例：`{"id": "...", "tokens": [...], "labels": ["O","B-质量","I-质量",...]}`
   - 方面情感：`data/processed/aspect_sentiment.csv`  
     列：`sentence`、`aspect`、`polarity`（及可选 `aspect_span`）
3. 训练 `BertForTokenClassification`；实体级 F1 **≥85%**；指标写入 `artifacts/metrics/ner_f1.json`。
4. 将 `aspect_sentiment.csv`（及划分说明）交 **陈江平** 与 **属性 BERT（待定）**。
5. 【路演】BIO 着色示例、5 类覆盖图、NER F1 卡 → `pitch_assets/no05_ner/`。
