## 4. 传入 → 技术处理 → 返回

| 阶段 | 内容 |
| ---- | ---- |
| **传入** | 一句评论 `sentence` |
| **中间技术** | 人工/半自动标 span → BIO；可选 `BertForTokenClassification` 训练 |
| **返回（推理）** | 实体列表（见下） |

**`aspect_sentiment.csv` 列（别改名）：**

| 列 | 含义 |
| -- | ---- |
| `sentence` | 原句 |
| `aspect` | 属性名，如「物流」 |
| `polarity` | 0 负 / 1 正 |
| `aspect_span` | 可选，原文片段 |

**`predict_entities(text)` 返回（对齐郑平高）：**

| 字段 | 含义 |
| ---- | ---- |
| `aspect` | 标准属性名 |
| `text` | 原文片段 |
| `start` / `end` | 起止位置 |
| `polarity` | 0/1 |
| `polarity_text` | 「正向」/「负向」 |

## 5. 怎么做（按顺序勾）

1. 代码放：`pipelines/aspect_ner/`（仓库里已有部分脚本可参考）

5. 把 csv 发给陈江平，并说明划分 seed  
6. 路演三图
