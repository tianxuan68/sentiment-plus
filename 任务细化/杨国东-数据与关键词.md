## 4. 传入 → 技术处理 → 返回

### 任务 A

| 阶段 | 内容 |
| ---- | ---- |
| **传入** | `train.csv`（中文）、`data.csv`（英文） |
| **中间技术** | Pandas 映射字段、去空、UTF-8；`random_state=68` 抽样 |
| **返回** | 统一表 + 抽样表 |

统一表列（别改名）：`id, text, label, overall, asin, review_time, lang, dataset`

### 任务 B

| 阶段 | 内容 |
| ---- | ---- |
| **传入** | 单条评论 `text` + `top_n`（默认 5） |
| **中间技术** | TF-IDF；KeyBERT（Sentence-BERT 句向量） |
| **返回** | `[{word, score}, ...]` |

**给郑平高的两个 HTTP：**

| 接口 | 传入 | 返回 |
| ---- | ---- | ---- |
| `POST /api/v1/keywords/extract` | `{text, top_n}` | `{keywords:[{word,score}]}` |
| `POST /api/v1/keywords/compare` | `{text, top_n}` | `{keybert:[], tfidf:[], overlap:[], keybert_unique_count}` |
