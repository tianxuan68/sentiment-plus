# 二、任务 A · 数据采集与数据集整理

| 项 | 内容 |
| -- | ---- |
| **功能模块** | 用户评价分析 |
| **使用技术** | 公开数据集、Pandas |
| **验收标准** | ①英文≥5 万条；②字段统一；③输出 `unified_reviews.csv`；④抽≥3000 句交 5 号 |

## 2.1 输入

| 文件 | 字段 |
| ---- | ---- |
| `data/raw/train.csv` | `sentence`、`label`、`dataset` |
| `data/raw/data.csv` | `reviewText`、`overall`、`asin`、`reviewTime` / `unixReviewTime` |

## 2.2 实现步骤

1. 校验中文行数、英文行数（英文 `len ≥ 50000`），打印缺失值统计。
2. 清洗：去空文本、统一 UTF-8、去掉明显乱码行；**不做情感训练混拼**。
3. 字段映射到统一 schema，写出 `data/processed/unified_reviews.csv`：

| 列名 | 来源 | 说明 |
| ---- | ---- | ---- |
| `id` | 自增 | 全组唯一 |
| `text` | `sentence` / `reviewText` | 原始评论文本 |
| `label` | `label`；英文可由 `overall` 映射或留空 | 中文 0/1；英文可只保留评分 |
| `overall` | 英文 `overall`；中文可空 | 0～4 |
| `asin` | 英文；中文可空 | 商品 ID |
| `review_time` | `reviewTime` / `unixReviewTime` | 趋势图用 |
| `lang` | `zh` / `en` | **禁止混训标记** |
| `dataset` | 来源名 | 可追溯 |

4. 从中文可用句中**随机抽样 ≥3000 句**（建议 `random_state=68`），导出：
   - `data/samples/aspect_annotate_pool.csv`（列：`id`、`sentence`）
   - 交 **5 号**；注明抽样种子与条数。
5. 可选：写 `data/README.md` 记录条数、字段、下载来源（不写大文件进 Git）。
