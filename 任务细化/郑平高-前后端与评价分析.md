## 4. 传入 → 技术处理 → 返回

| 阶段 | 内容 |
| ---- | ---- |
| **传入（用户）** | 一条评论 `text`，可选 `top_n` |
| **中间技术** | FastAPI 鉴权 → `httpx` 并行调 AI 三路（情感/关键词/属性）→ Vue + ECharts 展示 |
| **返回给前端** | `AnalyzeResult`（见下） |

**单条分析你聚合后返回的核心字段：**

| 字段 | 含义 |
| ---- | ---- |
| `sentiment` | `{label, label_text, prob}` |
| `keywords` | `[{word, score}]` |
| `aspects` | `[{aspect, polarity, polarity_text, prob}]` |
| `entities` | `[{aspect, text, start, end, polarity, ...}]` |
| `active_model` | 如 `"BERT"` |
| `source` | `mock` / `ai` / `mock_fallback` |
| `latency_ms` | 耗时 |

**环境变量（`.env`）：**

| 变量 | 默认 | 含义 |
| ---- | ---- | ---- |
| `SENTIMENT_AI_BASE_URL` | `http://127.0.0.1:8100` | AI 服务地址 |
| `SENTIMENT_AI_MOCK` | `true` | 演示 Mock；联调改 false |
| `SENTIMENT_AI_TIMEOUT` | `1.5` | 超时秒数 |
