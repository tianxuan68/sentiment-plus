# 三、实现步骤

1. **后端（`jeecg-fastapi`）**
   - 新增业务路由（建议前缀仍走 `/jeecg-boot` 体系）：评论分析相关 API。
   - 服务层 HTTP 客户端转发至 `sentiment-ai`（环境变量如 `SENTIMENT_AI_BASE_URL`）。
   - 聚合接口示例（实现时可拆）：

| 业务接口 | 作用 | 依赖 AI |
| -------- | ---- | ------- |
| `POST .../review/analyze` | 单条：情感+关键词+属性 | sentiment / keywords / aspect |
| `GET .../review/stats/polarity` | 正负比例 | 库表或 analytics 结果 |
| `GET .../review/stats/trend` | 时间趋势 | `unixReviewTime` / `reviewTime` |

2. **前端（`jeecgboot-vue3`）**
   - 新增「评论分析」菜单页（路径自定，如 `/sentiment/review`）。
   - 区块：评论输入框 → 分析结果（情感标签、关键词标签、属性列表）。
   - ECharts：**比例图**（`label` / `pred_label`）；**趋势图**（按时间聚合）。
3. 联调：单次分析链路端到端；演示机 **≤2 秒**（可缓存模型、预热）。
4. 【路演】系统首页全屏截图、技术路线图、10～15s Demo GIF/MP4 → `pitch_assets/zheng_pinggao/`。
