# 三、实现步骤

1. 正样本桶（`label=1`）跑 KeyBERT → Top10 优点；负样本桶（`label=0`）→ Top10 缺点。
2. 模型与参数（对齐主设计）：
   - `KeyBERT('paraphrase-multilingual-MiniLM-L12-v2')`
   - `keyphrase_ngram_range=(1, 2)`
   - `top_n=10`
   - `use_mmr=True`
   - `diversity=0.5`
   - `nr_candidates=20`
3. 导出：
   - `data/processed/pros_top10.csv`（列建议：`rank`、`phrase`、`score`）
   - `data/processed/cons_top10.csv`
4. 人工评测相关率 ≥80%（抽样打分表可放 `artifacts/metrics/pros_cons_human_eval.csv`）。
5. 可选推理接口交 1 号：`POST /api/v1/pros_cons/extract`，或直接提供静态 Top10 供前端展示。
6. 【路演】词云 + Top10 对照表 → `pitch_assets/deng_xinxiao/`。
