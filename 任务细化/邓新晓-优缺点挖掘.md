---

## 4. 传入 → 技术处理 → 返回

| 阶段 | 内容 |
| ---- | ---- |
| **传入** | 正文本列表（label=1）、负文本列表（label=0） |
| **中间技术** | KeyBERT + Sentence-BERT；`use_mmr=True`，`diversity=0.5`，`top_n=10`，`ngram=(1,2)` |
| **返回** | `pros:[{word,score}]`、`cons:[{word,score}]` |

**HTTP：**

| 接口 | 传入 | 返回 |
| ---- | ---- | ---- |
| `POST /api/v1/pros_cons/extract` | `{}` 或 `{top_n}` | `{pros:[...], cons:[...]}` |

CSV 列建议：`rank, word, score`

---

## 5. 怎么做（按顺序勾）

1. 代码放：`pipelines/pros_cons/`  
2. `load_labeled_corpus()`：按 label 分桶  
3. `mine_pros_cons()`：KeyBERT+MMR  
4. `export_top10_csv()` 写出两个文件到 `data/processed/`  
5. 人工抽查相关率，记录 `artifacts/metrics/pros_cons_human_eval.csv`  
6. 挂 HTTP（或告诉郑平高直接读 CSV）  
7. 路演图 → `pitch_assets/deng_xinxiao/`

推荐参数（与主设计一致）：

- 模型：`paraphrase-multilingual-MiniLM-L12-v2`  
- `keyphrase_ngram_range=(1,2)`，`nr_candidates=20`
