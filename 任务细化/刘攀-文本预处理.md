# 三、实现步骤

1. 在 `pipelines/preprocess/` 建脚本，建议文件：
   - `clean.py`：主流程
   - `stopwords.txt`：停用词表
   - `run_preprocess.py`：一键入口
2. 清洗规则（按序执行，写进函数注释）：
   - 去 URL、HTML 标签、多余空白
   - 保留中文、数字、必要标点（或按组约定去掉表情）
   - 空串丢弃并记日志条数
3. `jieba.lcut` 分词 → 去停用词 → `tokens` 用空格拼接为 `text_clean`。
4. 自检：随机抽 100 条，人工看「分词去停用词」合格率；目标 **≥95%**（记录在 `artifacts/metrics/preprocess_qc.json`）。
5. 导出 `data/processed/clean_train.csv`：

| 列 | 含义 |
| -- | ---- |
| `sentence_raw` | 原始句 |
| `tokens` | 分词列表序列化（JSON 字符串或空格串，组内统一一种） |
| `text_clean` | 去停用词后空格拼接 |
| `label` | 0/1 |

6. 下游只读本文件；**不要**改 `label` 划分。
