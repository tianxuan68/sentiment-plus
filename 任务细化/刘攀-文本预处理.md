## 4. 传入 → 技术处理 → 返回

| 阶段 | 内容 |
| ---- | ---- |
| **传入** | `train.csv` 里的 `sentence`（原文）、`label`（0负/1正） |
| **中间技术** | `re` 正则清洗 → `jieba` 分词 → 读 `stopwords.txt` 过滤 |
| **返回/产出** | 每一行变成下面 4 列（**列名不许改**） |

| 列名 | 含义 | 举例 |
| ---- | ---- | ---- |
| `sentence_raw` | 原始评论 | `物流很快！！！` |
| `tokens` | 分词结果 | `物流 很快` 或 JSON 数组（组内统一一种） |
| `text_clean` | 去停用词后，**下游统一读这列** | `物流 很快` |
| `label` | 标签 | `0` 或 `1` |

---

## 5. 怎么做（按顺序勾）

1. 代码放：`sentiment-ai/pipelines/preprocess/`
2. 写清洗：去 URL / HTML / 多余空格；空串丢掉并记数
3. `jieba.lcut` → 去停用词 → 拼成 `text_clean`
4. 随机抽 100 条人工看，合格率写到 `artifacts/metrics/preprocess_qc.json`（目标 ≥0.95）
5. 导出：`data/processed/clean_train.csv`
6. 画 1 张「清洗前/后」对照图 → `pitch_assets/liu_pan/`

**核心函数（名字建议固定）**

| 函数 | 传入 | 返回 |
| ---- | ---- | ---- |
| `clean_text(raw)` | 原句 | 清洗后字符串 |
| `tokenize(text)` | 清洗句 | 词列表 |
| `remove_stopwords(tokens)` | 词列表 | 过滤后词列表 |
| `run_preprocess()` | 输入/输出路径 | `{total, written, dropped, qc_pass_rate}` + 写出 CSV |
