# 三、实现步骤

1. 在 `pipelines/preprocess/` 建脚本，建议文件：
   - `clean.py`：主流程
   - `stopwords.txt`：停用词表
   - `run_preprocess.py`：一键入口
2. 清洗规则（按序执行，写进函数注释）：
   - 去 URL、HTML 标签、多余空白
   - 保留中文、数字、必要标点（或按组约定去掉表情）
   - 空串丢弃并记日志条数
3. `jieba.lcut` 分词 → 去停用词 → `tokens` 用空格拼接为 `text_clean`。
4. 自检：随机抽 100 条，人工看「分词去停用词」合格率；目标 **≥95%**（记录在 `artifacts/metrics/preprocess_qc.json`）。
5. 导出 `data/processed/clean_train.csv`：

| 列 | 含义 |
| -- | ---- |
| `sentence_raw` | 原始句 |
| `tokens` | 分词列表序列化（JSON 字符串或空格串，组内统一一种） |
| `text_clean` | 去停用词后空格拼接 |
| `label` | 0/1 |

6. 下游只读本文件；**不要**改 `label` 划分。

## 7.1 本岗必须实现的函数

```python
def clean_text(raw: str) -> str:
    """单条清洗：去 URL/HTML/多余空白，保留中文与必要标点。
    入参: raw — train.csv 的 sentence 原串
    返回: 清洗后字符串；空串表示应丢弃
    """

def tokenize(text: str) -> list[str]:
    """jieba 分词。
    入参: text — clean_text 输出
    返回: 词列表，如 ["物流", "很快"]
    """

def remove_stopwords(tokens: list[str], stopwords: set[str] | None = None) -> list[str]:
    """去停用词。
    入参: tokens — tokenize 输出；stopwords — 默认读 stopwords.txt
    返回: 过滤后词列表
    """

def process_row(sentence_raw: str, label: int) -> dict | None:
    """单行完整预处理。
    入参: sentence_raw — 原始评论；label — 0|1
    返回: {
        "sentence_raw": str,
        "tokens": str,       # JSON 或空格串，组内统一
        "text_clean": str,   # 空格拼接，供 TF-IDF/KeyBERT
        "label": int,
    } 或 None（空串丢弃）
    """

def run_preprocess(
    input_path: str = "data/raw/train.csv",
    output_path: str = "data/processed/clean_train.csv",
    stopwords_path: str = "pipelines/preprocess/stopwords.txt",
) -> dict:
    """一键入口。
    入参: CSV 路径、输出路径、停用词表
    返回: {
        "total": int,           # 输入行数
        "written": int,         # 写入行数
        "dropped": int,         # 丢弃行数
        "qc_pass_rate": float,  # 抽检合格率 0~1，目标 ≥0.95
        "output_path": str,
    }
    副作用: 写出 clean_train.csv
    """
```
