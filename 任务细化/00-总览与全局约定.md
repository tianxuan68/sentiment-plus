## 项目一句话

用户写一条商品评论 → 系统告诉他：**正/负情感、关键词、优缺点、属性情感** → 前端图表展示。

```
数据(杨国东) → 清洗(刘攀) → 三个情感模型(毛鑫泽→陈江平→胡潇潇)
                              → 关键词(杨国东) / 优缺点(邓新晓)
         抽样 → NER标注(5号) → 属性情感(陈江平/属性BERT)
全部 AI 结果 → 郑平高(前后端) → 页面展示 → 6号做 PPT
```

## 全组必须遵守（3 条）

1. **划分**：train/val/test = 8:1:1，`seed=68`，大家用同一份 `splits/`，禁止自己乱划测试集  
2. **中英不混训**：中文主训情感；英文主要做规模/评分展示  
3. **交 1 号**：凡要上页面的能力，最终都要能被郑平高的后端调用（HTTP 或约定好的 JSON 文件）

## 安装依赖（全组同一份）

在仓库根目录：

```powershell
pip install -r requirements.txt
```

前端：`cd jeecgboot-vue3` → `pnpm install` → `pnpm dev`  
后端：`cd jeecg-fastapi` → `python run.py`  

AI 版本：

| 版本 | 目录 | 启动 | 说明 |
|------|------|------|------|
| **1.0**（当前） | `sentiment-ai/` 或 `sentiment-ai-1.0/` | 端口 **8100** | 好评/差评二分类，郑平高联调这个 |
| **2.0**（骨架） | `sentiment-ai-2.0/` | 端口 **8200** | 多标签 → 动态标签，接口占位，等排期 |

```powershell
# 1.0
cd sentiment-ai
uvicorn app.main:app --port 8100 --reload

# 2.0（仅骨架）
cd sentiment-ai-2.0
uvicorn app.main:app --port 8200 --reload
```
