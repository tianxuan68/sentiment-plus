# 二、全局约定（全组共用，先读再写）

## 2.1 数据与划分（对齐主设计 §5.1）

| 项 | 约定 | 实现落点 |
| -- | ---- | -------- |
| 中文主数据 | `train.csv`：`sentence`、`label`（0负/1正）、`dataset`；约 4.5 万条 | `sentiment-ai/data/raw/train.csv` |
| 英文辅数据 | `data.csv`：`reviewText`、`overall`（0～4）、`asin`、`reviewTime` / `unixReviewTime` 等；≥5 万条 | `sentiment-ai/data/raw/data.csv` |
| 划分规则 | train:val:test = **8:1:1**，`random_seed=68`，全组共用同一测试集；**中英不混训** | `sentiment-ai/configs/split.json` + 共用划分脚本 |
| 清洗语料 | 刘攀产出 `clean_train.csv`（`sentence_raw`、`tokens`、`text_clean`、`label`） | `sentiment-ai/data/processed/clean_train.csv` |
| 属性样本 | 杨国东抽样 → **5 号** BIO + polarity → `aspect_sentiment.csv` 供 **陈江平 / 属性 BERT** | `data/samples/` → `data/processed/` |
| 情感对比链 | Baseline（毛鑫泽）→ TextCNN → BiLSTM（陈江平）→ BERT（胡潇潇）；**6 号**汇总 PPT | 四模型指标统一写入 `artifacts/metrics/` |

### 共用划分脚本（必须先落地，下游禁止各自 `train_test_split`）

```
sentiment-ai/scripts/make_split.py
  输入：data/raw/train.csv（或 processed/clean_train.csv）
  输出：data/processed/splits/
        ├── train_ids.txt
        ├── val_ids.txt
        └── test_ids.txt
  规则：stratify by label；random_state=68；比例 8:1:1
```

`configs/split.json` 示例字段：

| 字段 | 值 |
| ---- | -- |
| `random_seed` | `68` |
| `train_ratio` | `0.8` |
| `val_ratio` | `0.1` |
| `test_ratio` | `0.1` |
| `id_column` | 行号或自增 `id`（全组同一列） |
| `label_column` | `label` |
