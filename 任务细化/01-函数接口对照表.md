# 三、HTTP 推理接口（sentiment-ai → 郑平高转发）

| 路径 | 实现人 | 请求体 `result` 入参 | 响应 `result` 出参 | 郑平高封装函数 |
| ---- | ------ | -------------------- | ------------------- | -------------- |
| `POST /api/v1/sentiment/predict` | 胡潇潇 | `{ text: str }` | `{ label: int, prob: float, model?: str }` | `analyze_review()` 内 `_real_analyze()` |
| `POST /api/v1/sentiment/models/compare` | 胡潇潇 | `{}` | `ModelCompareResult` 见 schema | `get_model_compare()` |
| `POST /api/v1/keywords/extract` | 杨国东 | `{ text: str, top_n: int }` | `{ keywords: [{ word, score }] }` | `analyze_review()` |
| `POST /api/v1/keywords/compare` | 杨国东 | `{ text: str, top_n: int }` | `KeywordCompareResult` 见 schema | `compare_keywords()` |
| `POST /api/v1/pros_cons/extract` | 邓新晓 | `{}` 或 `{ top_n: int }` | `{ pros: [], cons: [] }` | `get_pros_cons()` |
| `POST /api/v1/aspect/predict` | 陈江平 / 属性BERT | `{ text: str, aspects: list[str] }` | `{ items: [{ aspect, polarity, prob }] }` | `analyze_review()` |
| `GET /api/v1/analytics/rating_distribution` | 统计待定 | — | `RatingDistribution` 见 schema | `get_rating_distribution()` |
| `GET /health` | 胡潇潇（app 主入口） | — | `{ status: "ok" }` | `get_ai_status()` |

# 四、业务后端（郑平高 · jeecg-fastapi）已实现函数

前缀：`/jeecg-boot/sys/review`（需登录）。实现文件：`app/services/sentiment_ai_client.py`。

| 函数 | 入参 | 返回类型 | 前端调用 |
| ---- | ---- | -------- | -------- |
| `analyze_review(text, top_n=5)` | `text: str`, `top_n: int` | `AnalyzeResult` | `POST /analyze` |
| `analyze_batch(texts, top_n=5)` | `texts: list[str]`, `top_n: int` | `BatchAnalyzeResult` | `POST /analyze/batch` |
| `get_polarity_stats()` | — | `PolarityStat` | `GET /stats/polarity` |
| `get_trend_stats()` | — | `list[TrendPoint]` | `GET /stats/trend` |
| `get_dashboard_summary()` | — | `DashboardSummary` | `GET /stats/summary` |
| `get_rating_distribution()` | — | `RatingDistribution` | `GET /stats/rating` |
| `get_pros_cons()` | — | `ProsConsResult` | `GET /pros-cons` |
| `get_model_compare()` | — | `ModelCompareResult` | `GET /models/compare` |
| `compare_keywords(text, top_n=8)` | `text: str`, `top_n: int` | `KeywordCompareResult` | `POST /keywords/compare` |
| `get_ai_status()` | — | `AiStatusResult` | `GET /ai/status` |

### 核心结构体字段（节选）

```python
# AnalyzeResult — 单条分析聚合（前端单条页）
AnalyzeResult(
    sentiment: SentimentResult,      # label: 0|1, label_text, prob
    keywords: list[KeywordItem],     # word, score
    aspects: list[AspectItem],       # aspect, polarity, polarity_text, prob
    entities: list[AspectEntity],    # aspect, text, start, end, polarity, polarity_text
    active_model: str,               # 默认 "BERT"
    source: str,                     # mock | ai | mock_fallback
    latency_ms: float | None,
    text_preview: str | None,
)
```

# 六、联调顺序（函数级）

1. 刘攀 `run_preprocess()` 产出 `clean_train.csv`

6. 杨国东 / 邓新晓 / 属性侧 各自 HTTP 路由挂到同一 `app.main`
7. 郑平高 `.env` 设 `SENTIMENT_AI_MOCK=false`，逐函数验证 `sentiment_ai_client.py`
