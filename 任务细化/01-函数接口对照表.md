## 2. AI HTTP（sentiment-ai → 郑平高转发）

| 路径 | 谁实现 | 传入 | 返回 result |
| ---- | ------ | ---- | ----------- |
| `POST /api/v1/sentiment/predict` | 胡潇潇 | `{text}` | `{label, prob, model?}` |
| `POST /api/v1/sentiment/models/compare` | 胡潇潇 | `{}` | 三模型 metrics |
| `POST /api/v1/keywords/extract` | 杨国东 | `{text, top_n}` | `{keywords:[{word,score}]}` |
| `POST /api/v1/keywords/compare` | 杨国东 | `{text, top_n}` | keybert/tfidf/overlap |
| `POST /api/v1/pros_cons/extract` | 邓新晓 | `{}` 或 `{top_n}` | `{pros:[], cons:[]}` |
| `POST /api/v1/aspect/predict` | 陈江平/属性BERT | `{text, aspects[]}` | `{items:[{aspect,polarity,polarity_text,prob}]}` |
| `GET /api/v1/analytics/rating_distribution` | 统计岗 | — | buckets/avg/total |
| `GET /health` | 胡潇潇 | — | `{status:"ok"}` |
