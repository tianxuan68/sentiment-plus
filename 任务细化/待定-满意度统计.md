# 二、实现步骤

1. 读 `unified_reviews.csv` / 预测结果表（若有 `pred_label`）。
2. 计算：
   - 正负比例：`label` 或 `pred_label`
   - 评分分布：英文 `overall`（0～4）直方图
   - KPI：正向率、均分、样本量等
3. 导出 `data/processed/satisfaction_report.json`（及可选 CSV），**交 1 号**挂 KPI 卡。
4. 【路演】饼图、评分柱状图、KPI 卡。
