## 4. 传入 → 技术处理 → 返回

| 阶段 | 内容 |
| ---- | ---- |
| **传入** | `unified_reviews.csv` |
| **中间技术** | Pandas / Numpy 聚合 |
| **返回** | 见下表（字段名对齐郑平高 schema） |

| 能力 | 返回要点 |
| ---- | -------- |
| 正负比 | `{positive, negative, total, positive_ratio, negative_ratio}` |
| 评分分布 | `{buckets:[{rating,count,ratio}], avg_rating, total}` |
| 趋势 | `[{name, value, positive, negative}]` |
| 满意度报告 | `{satisfaction_score, avg_rating, review_count, positive_ratio, trend_direction}` |

**HTTP（建议）：**

| 接口 | 返回 |
| ---- | ---- |
| `GET /api/v1/analytics/polarity` | 正负比 |
| `GET /api/v1/analytics/rating_distribution` | 评分分布 |
| `GET /api/v1/analytics/trend` | 趋势 |
