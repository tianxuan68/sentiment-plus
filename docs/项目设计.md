# 基于深度学习与自然语言处理的商品评论情感分析系统

> **定位说明（TianXuan / sentiment-plus）**  
> 本系统是总仓 **TianXuan** 下的独立子项目 **sentiment-plus**。  
> 技术底座为 Jeecg FastAPI + Vue3，**仅保留系统配置**，业务为评论情感分析。  
> - 后端：`jeecg-fastapi/`  
> - 前端：`jeecgboot-vue3/`  
> - 设计文档：`docs/`  
> - 后端依赖：`jeecg-fastapi/requirements.txt`

## 一、项目概述

项目的背景是现在电商平台每天都会产生大量用户评论，这些评论里面包含了用户对商品质量、价格、物流、服务等方面的真实反馈。但是由于评论数量非常大，人工很难快速分析这些信息，所以我们希望通过 NLP 技术自动挖掘评论中的有效信息。

这个项目主要解决三个问题。第一个是**情感分析**，通过机器学习和深度学习模型判断用户评论是正向还是负向，帮助了解用户整体满意度。第二个是**关键词提取**，从大量评论中找到用户关注的重点，比如商品的优点和缺点。第三个是**属性级情感分析**，比如用户评价一件商品时，我们不仅判断整体情感，还可以分析他对质量、价格、物流等不同方面的态度。

主要功能：

-   商品评论情感分类
-   用户评价分析
-   商品优缺点挖掘
-   评论关键词提取
-   商品属性情感分析

# 四、技术点标注

|                  | **BERT-NER**                                                 | **KeyBERT**                                                  |
| :--------------- | :----------------------------------------------------------- | :----------------------------------------------------------- |
| **大白话概念  ** | "文本中的专用名词标注" 一段话里的"人名"、"地名"、"机构名"、"时间"等特定词汇并打标签。 | "关键词提取" 将整段话和候选词都转成语义向量，相似度最高的即为关键词。 |
| **工作流程 **    | **① Token 化**：`BertTokenizer` 拆分为子词，加 `[CLS]` / `[SEP]`。<br /> **② 特征提取**：双向 Transformer 编码器提取上下文语义向量。 <br />**③ 序列标注**：每个 Token 传入线性层，预测 BIO 标签（用来标记文本中每个 token 属于实体的哪个位置）。 <br />**④ 实体抽取**：按标签连字成词，拼出完整实体。 | **① 候选生成**：切分为 n-gram 候选词/词组。 <br />**② 语义编码**：Sentence-BERT 分别计算**文档向量**和**候选词向量**。 <br />**③ 相似度排序**：计算文档与候选词的余弦相似度。 <br />**④ 多样性过滤**：MMR / MSS 剔除语义重复词，选出 Top-K。 |
| **常用 API**     | `transformers`<br />.`BertForTokenClassification` *(BERT 底座 + Token 分类头)* <br />可选接 `TorchCRF` 做 BIO 标签序列约束 | `keybert.KeyBERT` *(封装 **SentenceTransformer 的主类**)* `.extract_keywords(docs, ...)` — 提取关键词核心方法 |
| **常用参数**     | `pretrained_model_name_or_path`: 预训练权重<br />`num_labels`: 标签类别数<br />`input_ids`: 词向量 ID 序列 `[B, L]` <br />`hidden_size`: 隐层维度（默认 768） `classifier_dropout`: 分类头 Dropout | `model`: **SentenceTransformer 模型** `docs`: 输入文本 `keyphrase_ngram_range`: 词组长度范围，如 `(1, 2)` <br />`stop_words`: 停用词（`'english'`） `top_n`: 返回前 N 个关键词 <br />`use_mmr`: 是否开启最大边际相关性 `diversity`: MMR 多样性因子 `0.0~1.0` `nr_candidates`: MMR 候选池大小 |
| 参数解释1        | `classifier_dropout`：<br />分类层在训练时**随机**关闭一部分神经元的比例 | `use_mmr`： <br />**默认关闭时**，**KeyBERT**只看**这个词和整篇文章有多像**，按照相似度从高到低排序，取出来前**nr_candidates**个。**选出意思相近的词**            <br />**开启后**，KeyBERT 会额外考虑**这个词和已经选出的词有多像**，**尽量避开重复意思，让结果覆盖面更广**。 |
| 参数解释2        |                                                              | `diversity`： **<br />小（接近 0）**：只看和文章像不像，结果可能重复  <br />**值大接近 1**：只看彼此差异大不大，结果可能偏离文章主题 <br />**中间值0.5 左右）**：两者兼顾，最常用 |
| 参数解释3        |                                                              | `nr_candidates`： <br />先把所有**候选词按与文章的相似度排序**，**取出前 `nr_candidates` 个**组成一个子集，然后只在这个**子集内部用计算多样性和相关性**，挑出最终关键词。 |
| 参数解释4        |                                                              | `SentenceTransformer`： <br />模型分别计算**整篇文档的向量**和**每个候选词/短语的向量**，然后通过余弦相似度排序，找出与文档语义最接近的关键词 |
