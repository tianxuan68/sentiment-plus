# sentiment-ai 2.0 路线图

## 背景

1.0 只有好评/差评（`label` 0/1）。产品期望：

1. **多标签多分类**：一条评论可打多个细标签（物流快、质量好…）
2. **动态标签（拼多多风格）**：不同商品/类目，标签集合不同

## 阶段 2.0-A（下一步可排期）

- 标签表：固定枚举（可从属性 NER / 优缺点词归纳）
- 模型：多标签分类（sigmoid）或层级：先 1.0 极性 → 再标签
- 数据：需标注 `sentence → [tag1, tag2, ...]`（当前 `train2.csv` 没有）
- 接口：`POST /api/v2/tags/predict`

## 阶段 2.0-B（等安排）

- 输入增加 `product_id` / `category_id`
- 标签体系按类目配置加载（配置中心或 DB）
- 模型：类目条件模型 / 检索式标签 / 小样本适配
- 接口：`POST /api/v2/tags/predict_dynamic`

## 不做的事（暂时）

- 不替换 1.0，不改 8100 联调
- 不在未标注数据上硬训「开心/伤心」情绪，除非另开情绪数据源
